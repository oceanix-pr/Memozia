## 2. RootView — 主枢纽

### 2.1 结构（分层计算属性防类型检查超时）

```
body = dialogLayers                      // 弹窗/确认/导出/分享
  .overlay(progressOverlay)              // 录音中/导入中的底部进度条
  .modifier(ExportModifiers)             // 转写/总结导出（.md + .pdf）+ 录音分享
  .modifier(LifecycleTasksModifier)      // 启动任务链（串行）
```

内部分三层：`observerLayers`（NavigationSplitView + onReceive 通知监听 + onAppear 首屏）→ `sheetAndAlertLayers`（Privacy/Onboarding/Settings/Help 弹窗 + 错误 alert）→ 对话框层。

### 2.2 关键机制

- **通知监听**：菜单栏录音控制、录音全局热键、截图热键/菜单、截图保存入库、截图权限/错误弹窗、设置/帮助/剪贴板笔记（完整表见 [02-整体架构](02-整体架构.md) §6）
- **首屏门控**：`MemoziaPrivacyPolicy.needsConsent(...)`（同意布尔量 + 政策主版本号）→ PrivacyConsentView；`hasCompletedOnboarding` → OnboardingView；**大版本升级**（`onboardingCompletedVersion != currentAppVersion`）重新展示引导介绍新功能
- **侧边栏**：`RecordingListView` + 工具栏（**导入音频/视频**、新建快捷笔记、截图〔仅专业模式〕、删除、重命名、同步磁盘数据、开始/停止会议录音）+ macOS 文件拖拽导入（`AudioImportValidator` 校验）
- **详情分流**：按选中项类型分流 `RecordingDetailView` / `QuickNoteDetailView`，注入转写/取消/LLM 配置/提醒列表等依赖
- **处理队列接入**：详情列右上角工具栏常驻 `QueueToolbarButton`（图标随状态变化：有失败任务显示警示图标，否则按是否有活动任务区分；点击弹出 `QueuePanelView`）。RootView 的私有 extension 只做调度——把「转写 / 总结 / 润色标题 / 画面分析 / 拆解待办 / 一键处理」构造成 `TaskCenter` 的 Job/Step 投递，每个 Step 调用既有 ViewModel 方法并更新模型上的 `ProcessingStatus` 字段，并按上下文上报 `TaskErrorCode`（见 [02-整体架构](02-整体架构.md) §3.4）
- **一键处理三入口**：列表右键菜单、录音/录屏详情**播放条右侧**按钮、快捷笔记「拆解待办」**旁**按钮，均走 `presentOneClickPreview(_:)` → `OneClickPreviewView` 预览 → `enqueueOneClick(_:plan:)` 入队，链路为「转写（默认跳过已完成的，只有显式勾选「重新转写」才重跑并先备份手动编辑）→ 画面分析（录屏 / 导入视频）→ 总结 → 拆解待办」；文字/图片笔记无音轨，链路为「总结 → 拆解待办」。录音/录屏默认会议总结，文字/图片笔记按概要总结，**待办只落盘不写入提醒事项**。入队后顶部横幅提供「查看队列」入口（通知 `openTaskQueuePanel` 由工具栏按钮响应）
- **`ListItem` 选中模型**：`.recording(AudioRecording)` / `.quickNote(QuickNote)` 联合类型，支持 macOS List 多选（批量删除/导出）
- **导出子菜单**：转写与总结各自可导出 `.md` 或 `.pdf`（另保留复制文本与导出原始录音）。`.pdf` 走 `MarkdownPDFRenderer` 后台排版，排完再弹 `fileExporter`：排版不顶主线程，失败也能在用户选路径前弹错
- **合并录音**：专业模式仅多选至少两笔纯录音时显示右键入口，混选视频或笔记不显示。`RecordingMergeRequest` 固定确认文案，明确合并目标与删除行为；执行时显示进度、暂时禁用内容操作，完成后选中最新录音。详情播放器以音频 URL 重建，原条目 ID 不变也能播放新文件。
- **媒体清理**：专业模式在录音详情播放栏提供「清理录音」、图片详情提供「清理图片」，右键统一为「清理源件」。菜单直接挂在持有选中绑定的 `RecordingListView` 的 List 上；右键命中已选条目时用完整选中集合，点选中范围外的行则只作用于该行。`MediaCleanupRequest` 固定各类源文件、数量、预计体积与不可撤销后果，RootView 的提示框点击「确定」后才执行。结果用可滚动窗口列出全部失败原因与无源件跳过数量，大批量显示进度。清理后停止播放器、禁用重新转写、关闭原图全屏预览，保留图片类型与 OCR 阅读；条目和待办不删除。

## 4. RecordingDetailView — 录音详情

工具栏（播放控制、导出、删除）+ 音频播放器（`AudioPlayerState` 封装 AVPlayer，进度条/跳转）+ Tab 切换 **TranscriptView / SummaryView**；导入过原视频的**专业模式**条目额外显示 **VideoUnderstandingView**「画面」Tab（普通模式不展示该页签，规则见 `RecordingDetailView.availableTabs(experience:hasVideoAttachment:)`）。播放进度条下方的 `WaveformStrip` 用 `WaveformAnalyzer` 在本机提取的峰值显示有声与静音区间，支持点击/拖动跳转；分析中与读取失败分别显示状态，音频原件缺失时不显示声波图。页签栏下方渲染共享 `LLMModelSelectorBar`（仅总结/画面页签显示，转写用 STT 配置不展示），取代此前两个子视图各画一份的同状态选择条（曾被误读为“两个下拉框”）；页内改选会写回全局活动大模型配置并持久化。**播放条右侧**提供「一键处理」按钮，点击先弹出 `OneClickPreviewView` 预览，确认后由宿主投递到处理队列。macOS 布局适配（参数顺序见 RootView 调用处）。

录音保存完成后，RootView 复用刷新结果的非模态横幅，按信息/提醒显示图标，8 秒后收起；「查看详情」定位相应条目并展开 `captureReportSection`。录音详情从目录中的 `capture_report.json` 恢复音轨中断区间、恢复状态与静音证据；读取失败明确显示，不能当成无异常。录音中未恢复问题使用常驻横幅及「检查设备」，实际保存失败保留错误对话框与 Finder 入口。

正常格式协商自动重试成功、且没有采集影响记录时，只收起恢复横幅，不额外显示“已恢复”提醒。停录自动修复并成功合入的 PCM 分片通过报告的可选 `repairedSegments` 记录，详情显示自动处理结果；它本身是信息提示，不能抵消既有中断或降级警告。旧报告缺少该字段时仍可读取。

## 7. VideoUnderstandingView — 视频理解

视频条目的独立「画面」页由 `VideoUnderstandingView` 承担：内嵌 `VideoPlayer`，手动触发画面分析，明确显示“图片理解/本地 OCR”路径；缓存关键帧横向展示，点击后播放器精确跳转。切换到该页会暂停详情顶部的音频播放器，避免双路同时播放。

## 8. QuickNoteDetailView — 快捷笔记详情

图片预览 / 文字编辑 + AI 总结（流式）+ 待办提取 + 重命名/删除。与 RecordingDetailView 同构但面向 QuickNote 实体。底部操作栏在「拆解待办」**旁**提供「一键处理」（概要总结 → 拆解待办，先经 `OneClickPreviewView` 预览再入队）。顶部的模型选择器写回**全局活动大模型配置**并持久化（`SettingsViewModel.setActiveLLMConfig`），与设置页、录音详情的模型选择是同一份偏好，重开笔记或重启应用后保持一致。

### 8.1 文字笔记转语音

`QuickNoteDetailView` 的文字笔记仅在应用语言为简体/繁体中文，或跟随系统且系统第一首选语言为简体/繁体中文时提供「转为语音」入口；非中文隐藏入口，切换到非中文时关闭已打开的面板并取消合成。`NoteSpeechAvailability` 优先使用显式应用语言；跟随系统时读取系统全局 `AppleLanguages`，避免应用覆盖/语言缓存影响判定，也不因第二首选语言含中文而开放。编辑正文/总结期间不可打开。`NoteSpeechView` 与 `NoteSpeechViewModel` 使用打开时的正文/总结快照，支持系统音色语言/地区、实际标注的性别、语速、前段试听、播放和完整音频导出。性别未知的音色仅显示名称；缺少音色时引导在系统设置下载后刷新。面板关闭即取消当前任务并清理暂存音频，不自动创建录音条目，也不放入后台续跑队列。

`SpeechTextPreparer` 复用 `TranscriptMarkdownBuilder`，整理标题、链接名、列表、引用与表格，跳过代码块/图片；长文优先按句末分段，保留字符顺序。`NativeSpeechService` 串行调用 `AVSpeechSynthesizer.write`，音频回调通过锁保护的 `SpeechAudioSink` 写入 WAV，不继承 MainActor 隔离。取消封住写入并恢复等待方，30 秒无回调看门狗处理挂起，块令牌忽略迟到结果。`SpeechAudioEncoder` 在独立 actor 流式编码 M4A；MP3 按系统编码能力开放，当前未附带第三方编码器。AAC 由系统选择与音色采样率匹配的码率。

音频写入权限为仅当前用户的独立临时目录；不进入条目扫描或录音恢复。导出使用保存面板，在目标目录暂存后原子替换；取消/失败不覆盖旧文件。转语音相关文案在 `Localizable.xcstrings` 提供全部 21 种支持语言（与 `project.yml` 的 `knownRegions` 一致）。回归测试见 `NoteSpeechTests.swift`。

## 9. SettingsView — 设置中心

### 9.1 布局

sidebar（分组列表，顶部带「设置与命令」搜索框）+ detail（分组表单）。

侧边栏搜索（`.searchable`）同时过滤设置页名称与应用命令：命令结果的名称与**当前快捷键**取自 `AppCommandCatalog`（与菜单栏、应用菜单、帮助页同一份描述），点选后跳到该命令对应的 `settingsDestination` 设置页；没有对应设置项的命令（如 ⌘N 新建笔记）只作名称与快捷键展示。

`SettingsView` 通过 `AppExperienceStore` 切换两套信息密度：普通模式只显示语音转写组件准备、智能服务连接、会议场景、热键、数据状态和关于；专业模式显示全部引擎、模型、捕获、热键、待办、词典、声纹和存储控制。模式开关位于“关于”，切换后当前不可见的设置页会自动回到首个可见分组。

### 9.2 设置分组

| 分组 | 内容 |
|------|------|
| stt 语音转写 | 引擎模式、本地模型管理（下载/选择文件夹）、云端 API 配置、语言；本地模型下载经处理队列（`TaskCenter.whisperDownloadJob`），可在队列面板暂停 / 继续（断点续传） |
| llm 大模型 | 多套配置 CRUD（name/baseURL/model/apiKey/isLocal/supportsVision）、连接测试 |
| recording 录音 | 来源（mic/systemAudio/mixed）、输入设备与「录音开始时静音麦克风」（见 [04 音频采集](04-录音与音频采集.md) §2）、磁盘空间、静音提示选项 |
| screenshot 捕获 | 屏幕录制权限、默认捕获模式、录屏偏好（热键已迁出，见下） |
| hotkeys 热键 | **全局热键录制**（录音 / 截图 / 全屏直拍）、注册失败状态、`⌃⌘R` 冲突回退说明；两种模式均可见（普通模式隐藏「全屏直拍热键」行） |

### 9.3 普通模式的渐进披露

- 录音设置用“线上会议 / 面对面会议”映射采集源，不显示轨道、设备和静音策略。
- 总结只提供一个自动生成入口；模型选择、会议/概要模板指定、高级编辑和待办结构维护仅在 Pro 显示。
- 已有视频画面要点在普通模式仍可阅读，但不能新建/重新分析或清理原始视频，避免切换模式造成用户感知的数据丢失。
- 列表在普通模式收敛为单选，不显示批量、隐藏与标题润色入口；专业模式恢复原有多选与上下文菜单。

## 10. MarkdownView — Markdown 渲染器

界面与 `MarkdownPDFRenderer` 共用 `TranscriptMarkdownBuilder.parseBlocks` 和 `TranscriptBlock`，避免阅读与导出使用不同的块级语法。支持 H1–H6 与 Setext 标题、段落软换行/显式换行、带缩进层级和勾选状态的列表、反引号/波浪号围栏、嵌套引用、分隔线及管道表格。表格要求表头后有列数匹配的分隔行，外围竖线可省略，保留空单元格、转义竖线和列对齐；短行补空单元格，超出表头的单元格忽略。

`MarkdownView` 用原生 Grid 展示表格，长单元格换行、宽表格横向滚动。标题、段落、列表与单元格的行内格式统一使用 `AttributedString(markdown:options:.inlineOnlyPreservingWhitespace)`；代码保留字面内容。搜索高亮也适用于标题、代码和单元格。`TranscriptCache` 提供后台预解析的转写块；其他静态文本使用有容量和字节上限的多篇 LRU 缓存。

`StreamingMarkdownView` 用于录音和快捷笔记总结，后台合批解析后更新界面，不逐 token 在主线程解析全文。PDF 逐格排版并绘制边框，跨页重复普通表头，超长单元格分段续页；巨大表头自身需要分页时不重复。PDF 行内样式仍由 CoreText 导出实现负责（删除线只去标记），不承诺完整 CommonMark/GFM、HTML、公式或图片渲染。

相关回归用例位于 `MarkdownPDFRendererTests.swift`（含共用解析器、表格分页与长单元格测试）。

## 11. HelpView / OnboardingView / PrivacyConsentView

- **HelpView**：内置帮助，覆盖会议录音（含「录音开始时静音麦克风」预设与采集完整性报告）、导入、快捷笔记、转为语音、转写、声纹识别、总结、AI 待办、智能截图、菜单栏/后台录音、录音管理、数据隐私、快捷键；「快捷键」小节不硬编码，由 `AppCommandCatalog.shortcutReferenceIDs` 生成（名称与当前快捷键同上）
- **OnboardingView**：功能特性引导页（大版本升级重新展示）。普通模式使用精简主链路页面，Pro 保留完整功能介绍（「快捷笔记」页含转语音说明）。引导页**不再引导下载模型**：转写与说话人区分的模型准备都发生在实际使用时（系统语音识别按语言资产按需安装，说话人分离模型由 `SpeakerDiarizationService.ensureModelsReady` 首次使用时自动下载，失败则提示并降级为不做分离）。
- **PrivacyConsentView**：首启隐私同意（数据收集、权限用途、传输、本地存储、屏幕共享说明、用户权利、第三方服务约束；`interactiveDismissDisabled` 强制选择）
