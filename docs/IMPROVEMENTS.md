# 六项优化：实现入口、兼容边界与验收

> 本文说明代码设计与验收要求，不表示已经通过构建、测试或发布验收。工程配置以 `project.yml` 为准；新增源文件后须重新执行 XcodeGen，不手改生成工程。

## 1. 端点信任与文本脱敏

入口：设置 → 大模型 → 编辑配置。实现：`EndpointPolicy`、`LLMConfig` / `LLMConfigDraft`、`LLMConfigSnapshot`、`LocalLLMCapabilities`。

- `isLocal` 继续用于推理参数适配，但不再授予 HTTP 或免脱敏权限。
- 回环地址（localhost、127/8、::1）允许 HTTP。请用 127.0.0.1 作为客户端地址，而非监听通配地址 0.0.0.0。
- 私有 IPv4（10/8、172.16/12、192.168/16）使用 HTTP 必须明确开启“允许内网地址使用明文 HTTP”；更改 Base URL 会清除此许可。升级后的旧配置默认未授权，需重新核对保存。
- 公网必须 HTTPS。DNS 名称不会被推断为可信内网；内网域名和私有 IPv6 请使用 HTTPS。局域网模型仍可通过私有 IPv4 加独立授权使用。
- LLM、模型列表、能力探测、待办与敏感词扫描请求不自动跟随重定向，避免转发 API Key 或用户内容；网关应直接配置最终端点。
- 有效去标识化总开关开启时，非回环端点（包括内网）默认对文本脱敏；回环可另开“也对本机回环服务的文本脱敏”。关闭总开关仍表示用户选择不脱敏。
- 图片和视频帧不是文本脱敏对象；不能据此宣称画面已经去标识化。
- 词典中的敏感词扫描处理未脱敏原文，只允许本地标记且实际为回环端点的模型，不允许内网或公网端点。它与普通总结的内网支持是不同的安全边界。
- 模型配置的旧导入/导出仍是设备密钥方案；迁移文件不会自动授予内网 HTTP 许可，内网 HTTP 配置可能被导入预检判为无效，需手动重建并授权。

## 2. 长内容分段总结

实现：`SummaryChunking`、`LLMService.generateSummary`、`SummarySources`。

- 以字符预算顺序切分全文，不再静默仅保留转写前缀；分段结果继续分层归并。
- 每轮检查取消；空结果、压缩后没有变短、超过归并层数均明确失败，不丢弃尾段来假装成功。
- 分段过程中不向最终正文拼接中间结果，最终输出附分段覆盖提示。
- 录音输入使用独立的来源版 Markdown，时间链接取自实际转写片段；复制、导出和编辑用的干净转写格式不变。严格解密失败则停止，不把解密告警作为会议内容发给模型。
- 待办提取也顺序处理全部文本分段，某段请求失败不会发布“全文完成”的结果。

**边界**：字符预算不是模型专属 token 计数；短上下文模型仍可能拒绝请求。归并是有损摘要，全部输入参与不等于每条信息均保留。尚无分段断点续跑、精确进度或跨段待办语义去重；长会议信息保真、耗时与费用需要使用固定评估集实测。

## 3. 本地全文搜索

入口：侧栏“搜索标题、原文、总结或待办”。实现：`FullTextSearch`、`RecordingListView`、`SourceNavigation`、`RecordingDetailView`。

- 搜索标题、转写、总结、画面要点、笔记正文/OCR 和待办标题/备注，大小写与重音不敏感。
- 只传递加密字段快照到后台，在内存中解密匹配，不创建明文持久索引。
- 保持防抖，取消过时搜索；部分读取或解密失败时显示“结果可能不完整”，不当成完整空结果。
- 结果展示命中片段；带转写时间的录音结果可打开条目并定位音频播放。该入口不是自动逐词选中或高亮原文。
- 待办及历史文件读取有类型、符号链接和单文件大小预检。海量条目仍需逐次扫描，尚未取得性能对照数据。

## 4. 用户口令保护的跨设备备份

入口：设置的数据存储页 → 跨设备加密备份。实现：`PortableBackup`、`PortableBackupSection`。

### 创建

1. 停止录音，等待处理队列结束，关闭其他编辑操作。队列读失败不视为空队列。
2. 输入并确认至少 12 个字符的口令，选择当前数据目录以外的位置。
3. 导出前等待 `EntryMirrorStore.flush()`；枚举条目文件，创建前后比较路径、大小和修改时间。发现变化则失败，不发布有效备份目录。
4. 保存整个 `.memoziabackup` **目录包**（不是单个 ZIP 文件），连同其中的所有文件一起复制到目标设备。口令请另行安全保管。

### 格式和范围

- 版本 1：随机盐，PBKDF2-HMAC-SHA256（600,000 轮）派生 256 位密钥；AES-GCM 认证加密清单和约 1 MiB 的文件块，路径与块序号作为附加认证数据。
- 不导出设备密钥或 API Key。条目文本在内存中解开设备加密后以口令密钥归档；媒体也受归档加密保护。
- 包括符合条目目录规则的支持媒体、元数据、转写、总结、画面要点、笔记正文/OCR、待办及总结历史。
- 不含 SwiftData 数据库、用户设置、模型配置、词典、声纹库、模型资源或后台队列；不是应用全部状态的镜像。旧 12/14 位条目目录及月份归档目录兼容。
- 目录和后缀按白名单处理；不支持的文件不纳入，并报告跳过数。路径穿越、符号链接、重复目标和损坏数据均拒绝；单文本及清单约 32 MiB、文件数 100,000 的安全上限，超限不会发布不完整备份。

### 恢复与预检

1. 在目标 Mac 输入原口令，选择整个备份目录，再选择当前资料目录之外的目标位置。
2. 校验版本、路径与块清单，逐块验证认证标签，在私有暂存目录还原。文本以目标设备密钥重新加密；转写/总结/画面经独立 `EntryMirrorStore` 写入并确认落盘。
3. 成功后发布全新的 `Memozia-restored-*` 目录，**不合并、不覆盖当前库、不自动切换资料位置**。
4. 提醒事项外部标识和目标列表标识清空，状态回到待处理，避免在另一设备上误显示“已同步”；原有人工核对状态保留。
5. 在设置中选择恢复根目录并重启，核对条目数量、标题、隐藏状态、音频、图片、转写、总结和待办后，再考虑清理旧数据。

**恢复演练必须使用另一台 Mac**，且在确认前保留原资料和原备份。错误口令、损坏块、取消、磁盘满与镜像失败均应验收；不能仅凭包可生成就断言可恢复。

**边界与失败暂存**：当前没有全局编辑冻结锁，不是数据库事务快照；文件大小/修改时间检测也不是抵御外部恶意并发改写的机制。恢复失败的 `.Memozia-restore-*` 隐藏目录可能保留，以免清理与迟到镜像写入互相踩踏；目录权限为 0700，文本采用设备加密，媒体保留应用原有文件形式。它不会被当成成功恢复结果，可能占用磁盘；确认应用已重启且无写入者后再由用户处理。不要把失败暂存说成所有内容均为加密密文。口令遗失无法恢复。

## 5. 来源、确认状态和总结历史

实现：`TodoItem`、`TodoExtractionService.validateEvidence`、`SummaryView` 的共用待办行/编辑器、`SummaryHistory`、`SummaryHistoryButton`。

- 新待办可携带引文、已有片段时间链接、显式负责人及人工确认状态；旧 JSON 缺少这些字段仍可读取，默认“待核对”。
- 引文须逐字存在于提取输入；时间链接和引文须存在于同一输入块，负责人必须在输入中出现。图片直提没有可逐字核验的文本来源，不保留模型自行生成的来源字段。
- 录音总结的来源链接点击时还须匹配现有转写片段时间；AI 生成的任意时间不会被当成已验证来源。
- 待办可能从总结而非原始录音转写提取。因此，输入匹配只代表“能回查所供文本”，不证明会议事实正确；日期、负责人和行动内容仍需用户勾选核对。
- 编辑和重新生成总结前保存加密历史副本；保存失败则停止替换旧内容。历史页支持查看和复制，恢复由用户在编辑器中显式完成，不自动覆盖现有总结。
- 历史保留不等于已解决所有并发编辑冲突；历史数量、磁盘体积与长列表性能仍需运行验收。

## 6. 测试与质量门禁

- `ImprovementRegressionTests` 覆盖端点信任、脱敏决策、Unicode 全量分段、归并失败与取消、来源构造/校验、搜索片段、旧待办兼容、恢复同步状态重置、路径安全、口令派生与认证失败、历史加密、备份往返与损坏恢复等。
- 既有配置和安全测试更新为独立内网许可语义。
- CI 增加真实应用启动冒烟，并保留 `.xcresult`；是否能在所用 Mac runner 的 GUI/TCC 环境运行仍需触发验证。
- 截图验证缺少基线即失败，CI 禁止录制。视觉套件通过 `workflow_dispatch.visual_regression` 显式启用；当前还不是默认 PR 视觉门禁。
- 真实 PNG 基线必须在固定 Mac、显示设置和语言环境中显式录制并人工审核；参见 [基线说明](../MemoziaUITests/Baselines/README.md)。没有基线时不得将完整 UI 套件报告为通过。
- 新文案已进入 `Localizable.xcstrings`，新增条目当前仅有简体中文，其他语言待翻译与审核，不能宣称多语言完成。

## 验收执行顺序

在具备工具、依赖与明确主机执行授权的 Mac 上执行：

```sh
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Memozia.xcodeproj -scheme Memozia -configuration Debug -destination 'platform=macOS' build
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Memozia.xcodeproj -scheme Memozia -configuration Debug -destination 'platform=macOS' test
python3 Scripts/check_l10n.py --quiet
```

完整 `test` 包含 UI 截图要求，需先按基线说明准备真实基线，不能临时跳过失败来宣称整体通过。构建必须保留 Verify Embedded Frameworks 阶段。

随后手工验收：旧数据库迁移与现有配置、内网模型重新授权、PII 扫描拒绝非回环、总结取消/失败/尾段覆盖、搜索并发与音频定位、总结修订保留、待办确认及提醒事项写入确认、备份取消/损坏/低磁盘空间，以及另一台 Mac 的完整恢复。

本轮自动检查仅可用于它们实际覆盖的范围。语法解析不包含 Swift 6 类型/actor 检查、SwiftData 宏展开、链接、网络兼容性、权限、UI 或恢复语义验证；未执行的项目构建和测试必须继续标为未验证。
