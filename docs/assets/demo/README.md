# Memozia workflow media

- `memozia-workflow.mp4`: 45-second, silent, 1600 × 1120 H.264 tour.
- `memozia-workflow.gif`: compact inline preview of the same tour.
- English app UI; captured from an isolated local Memozia development build.

The app window is real. Meeting names, transcripts, summaries, speakers, and tasks are fictional fixtures. The tour opens the workspace, selects a prepared meeting, switches from transcript to summary, and scrolls to its editable tasks. It does not perform a new recording, run inference, write to Reminders, or measure processing speed.

The README shows three real screenshots before the animated tour. Four-language stills are in `../screenshots/`. Non-Chinese screenshot interfaces use the Memozia brand without the Chinese subtitle.
