# Memozia 9.8.8 (168)

- Model download progress now updates while large files are transferring. Cancelling a download preserves its resume information so you can continue later.
- Built-in model files are stored under `~/Documents/Memozia/LLM`. Opening model settings or using the model migrates existing files and resume records from the previous location without downloading them again.
- Settings now shows the model folder and a **Delete Built-in Model** button. Deletion requires confirmation, waits for current inference to finish, and clears model files and unfinished downloads. Files remain protected while another process is downloading or using the model. The next use asks you to download the model again.

- 修复大文件传输期间下载进度停在 0% 的问题。取消下载后保留续传信息，可在重试时继续下载。
- 内置模型保存到 `~/Documents/Memozia/LLM`。打开模型设置或使用模型时，会迁移旧目录中的模型与续传文件，复用已下载内容。
- 设置页显示模型文件夹，并新增「删除内置模型」按钮。删除前需要确认，执行时等待当前推理结束，清理模型及未完成下载；其他进程仍在下载或使用时会提示稍后重试。删除后再次使用会重新询问下载。

This Apple Silicon preview requires macOS 15 or later. The app is ad-hoc signed with Hardened Runtime enabled and has not been notarized by Apple. Sparkle verifies the update ZIP using Ed25519. Model weights download separately from the app.

Memozia 9.7.0 and later can check for updates in the app. For a first installation, extract the ZIP and copy `Memozia.app` to Applications. macOS may ask you to confirm access to the Memozia Keychain item when opening protected data after an upgrade.
