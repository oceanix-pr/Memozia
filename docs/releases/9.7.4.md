# Memozia 9.7.4（159）

- 修复菜单栏图标偏上：将 SF Symbol 的可见笔画按实际像素边界归一化，放入 22pt 的普通模板画布，避免状态按钮再次应用字体基线偏移。
- 保留 A 版线条图标及约 18pt 可见尺寸，分别生成 1×、2×、3× 图像表示，继续由系统适配深浅色与高亮。
- 增加可见像素居中回归测试；真实 NSStatusBar 普通与高亮状态的像素检查确认垂直偏差为 0。

适用于 Apple Silicon（arm64）、macOS 15 或以上。本包沿用现有 ad-hoc 签名的未公证预览分发，未经 Apple Developer ID 签名和公证；保留本地签名所需的单应用库加载例外，更新 ZIP 另经 Sparkle Ed25519 签名。

9.7.0 及以上版本可在应用内检查更新。更早的未配置更新源版本需手动解压 ZIP，并将 `Memozia.app` 复制到「应用程序」替换旧版。首次打开可能需要按 macOS 提示允许。

验证包括完整 macOS 单元测试（关闭并行、麦克风恢复与媒体清理 suites 独立运行）、Release 构建、实际草稿附件校验和 Ed25519 验签、深层代码签名与启动检查、普通及高亮状态的像素居中，以及公开 stable 更新源发现检查。真实录音中的跨版本安装及系统权限衔接未完成全部人工回归。
