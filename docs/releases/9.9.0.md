# Memozia 9.9.0 (170)

## English

- Open **Help → Getting Started** at any time. The guide follows your current mode and starts on the first page each time you reopen it. After accepting the privacy policy, you can also start a recording, import a file, or create a note directly from the empty library.
- Normal Mode remembers whether you record online meetings with microphone and system audio, or in-person meetings with the microphone. When you import a video, Normal Mode processes its audio track. For your first summary, you can download the on-device model or connect a cloud service.
- Set the transcription language, Chinese writing system, and summary language separately for each recording. Notes also have a summary language. Summaries follow the source language by default, and queued jobs retain the choices you made when starting them.
- Search Help in your interface language. The answers about missing meeting audio and generating a summary show your recording or model settings and link to the relevant controls. You can change the interface language on the privacy screen or in **Settings → About**, then restart. The guide, Help, and Settings follow Arabic reading direction.

## 简体中文

- 随时从 **帮助 → 首次使用指引** 重看当前模式的操作说明，每次打开都从第一页开始。首次同意隐私政策后，可直接在主窗口录音、导入文件或新建笔记。
- 普通模式会记住会议类型。线上会议同时录制麦克风和系统声音，面对面会议使用麦克风。导入视频时只处理音轨。首次生成纪要时，可下载本机模型或连接云服务。
- 每条录音可分别选择转写语言、中文字形和纪要语言，笔记也可以单独选择纪要语言。纪要默认跟随原文，排队任务会保留发起时的语言选择。
- 可用当前界面语言搜索帮助。「录不到对方的声音」和「怎么生成纪要」会显示当前录音场景或模型状态，并可打开相关设置。界面语言可在隐私页或 **设置 → 关于** 中切换，重启生效。阿拉伯语下，指引、帮助和设置按从右到左的顺序排列。

## Installation / 安装

This Apple Silicon preview requires macOS 15 or later. It uses ad-hoc signing with Hardened Runtime and is distributed without Apple notarization. Sparkle verifies the update ZIP with Ed25519. In Memozia 9.7.0 or later, choose **Check for Updates**. For a first installation, extract the ZIP and move `Memozia.app` to Applications.

本预览版适用于搭载 Apple Silicon、运行 macOS 15 或更高版本的 Mac，采用临时签名并启用 Hardened Runtime，尚未经过 Apple 公证。Sparkle 使用 Ed25519 验证更新包。Memozia 9.7.0 及以上版本可在应用内检查更新。首次安装请解压 ZIP，将 `Memozia.app` 拷贝到「应用程序」。
