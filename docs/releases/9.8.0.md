# Memozia 9.8.0（160）

- 快捷笔记的「文字内容」现在可以显示 Markdown 标题、列表、引用、表格和代码块。普通换行保留，编辑和复制均使用原文。
- 改善 OpenAI 兼容接口和 Claude 的模型请求处理，覆盖总结、图片理解和待办提取。会议总结沿用原始时间戳，旧总结里的录音跳转链接会显示为普通时间。
- 补齐隐私政策、设置和错误提示的多语言显示。简体与繁体中文界面使用各自的产品名称。
- 应用包补齐第三方许可与版权声明。说话人分离使用同版本的 Sherpa 官方无 TTS 构建，笔记转语音由 macOS 系统音色在本机合成。

本版本是适用于 Apple Silicon（arm64）和 macOS 15 或以上的未公证预览版。应用使用 ad-hoc 签名并保留 Hardened Runtime，更新 ZIP 另经 Sparkle Ed25519 签名。

9.7.0 及以上版本可在应用内检查更新。首次安装或从更早版本升级时，请解压 ZIP 并将 `Memozia.app` 复制到「应用程序」。
