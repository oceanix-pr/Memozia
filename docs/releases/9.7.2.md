# Memozia 9.7.2（157）

- 菜单栏采用用户选定的 A 版「柔角折页」自定义 SF Symbol：圆角折角纸张搭配简洁连续声波，保持单色线条风格。
- 校正图标可见外轮廓的水平与垂直中心，并同步将声波对齐纸张中心；提供 Small / Medium / Large 符号轮廓，由系统适配菜单栏明暗与高亮。

本包适用于 Apple Silicon（arm64）、macOS 15 或以上，沿用现有 ad-hoc 签名的未公证预览分发，未经 Apple Developer ID 签名和公证；保留本地签名所需的单应用库加载例外，更新 ZIP 另经 Sparkle Ed25519 签名。

9.7.0 及以上版本可通过应用内「检查更新」获取；更早的未配置更新源版本需要手动解压 ZIP，将 `Memozia.app` 复制到「应用程序」替换旧版。首次打开可能需要在「系统设置 → 隐私与安全性」允许。

发布验证包括完整 macOS 单元测试（媒体清理 suite 隔离运行）、Release 构建、实际草稿附件的 SHA-256 与 Ed25519 验签、解包后签名和启动检查、菜单栏符号渲染，以及公开 stable 更新源的版本发现。真实录音期间的跨版本安装和系统权限衔接未完成全部人工回归。
