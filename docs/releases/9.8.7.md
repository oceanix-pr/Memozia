# Memozia 9.8.7 (167)

- Choose **Built-in Qwen3.5-2B** for text summaries, image understanding and to-do extraction on your Mac, without an API key. It is the default model when you have no saved API configurations. You can select it in Settings or the model picker.
- The first use asks you to download approximately 1.8 GB of model files. Choose Hugging Face or HF Mirror, then continue your operation after the download. Simplified Chinese defaults to HF Mirror. Other languages default to Hugging Face.
- Downloads verify the pinned model files before use. Once installed, the built-in model runs locally. Longer summaries are processed in smaller sections to fit its context window.

- 可选择「内置 Qwen3.5-2B」，在 Mac 上完成文字总结、图片理解和待办提取，无需 API Key。没有已保存 API 配置时，默认使用内置模型。也可在设置或模型选择器中选择。
- 首次使用会询问是否下载约 1.8 GB 的模型文件，可选择 Hugging Face 或 HF Mirror。下载完成后自动继续当前操作。简体中文默认使用镜像源，其他语言默认使用官方源。
- 模型文件经过固定版本和完整性校验后使用。下载完成后，内置模型在本机运行。较长内容会分段处理，以适应模型的上下文长度。

This Apple Silicon preview requires macOS 15 or later. The app is ad-hoc signed with Hardened Runtime enabled and has not been notarized by Apple. Sparkle verifies the update ZIP using Ed25519. The model weights download separately from the app.

Memozia 9.7.0 and later can check for updates in the app. For a first installation, extract the ZIP and copy `Memozia.app` to Applications. macOS may ask you to confirm access to the Memozia Keychain item when opening protected data after an upgrade.
