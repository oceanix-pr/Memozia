# Memozia 9.8.6 (166)

Meeting recordings can now capture audio from other apps with macOS’s system audio recording permission. Microphone-only recordings need only microphone access. Memozia asks for screen recording access when you take a screenshot or record video.

If system audio cannot start, the main window offers to open System Settings or use just the microphone for this recording. Choosing the microphone keeps your usual recording source for the next meeting.

会议录音现在可以只授权系统录音来录制其他应用的声音。仅录麦克风时，只需麦克风权限。截图或录制视频时，Memozia 才会请求屏幕录制权限。

如果系统录音无法启动，可在主窗口打开系统设置，或选择「本次仅录麦克风」。下次会议仍会使用原先选择的录音来源。

This preview runs on Apple Silicon with macOS 15 or later. It is ad-hoc signed with Hardened Runtime and has not been notarized by Apple. Sparkle verifies the update ZIP using Ed25519. To update from Memozia 9.7.0 or later, check for updates in the app. For a first installation, extract the ZIP and copy `Memozia.app` to Applications.
