# Memozia 9.8.4 (164)

- **Clean Up Originals** now includes leftover silence-padding audio files (`capture_silence_<UUID>.caf`) in the selected recording folders. The confirmation dialog counts these files and includes their size in the estimated space to recover.
- Recordings whose main audio has already been removed can still have these leftover files cleaned up from the list context menu.
- Report bugs or request features from **Settings → About → Feedback**. **Open Email Draft** prepares your message for review in your email app, and the form provides a copyable contact address.

This unnotarized preview supports Apple Silicon (arm64) on macOS 15 or later. The app is ad-hoc signed with Hardened Runtime enabled. The update ZIP is signed with Sparkle Ed25519.

Memozia 9.7.0 and later can check for updates in the app. For a first installation or an upgrade from an earlier version, extract the ZIP and copy `Memozia.app` to Applications.

The macOS unit suite recorded 550 passes and seven environment-gated skips, including the source-cleanup regression and update installation safeguards. Live capture, installation during a real recording, actual worker handoff, and an in-place upgrade with system permission retention were not exercised end to end.
